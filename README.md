# Pong Game in Python

This is a simple Pong game built using Python's Turtle graphics library.  
I created it while learning object-oriented programming and basic game logic.

## Features
- Two-player mode
- Smooth paddle movement
- Ball speed increases over time
- Scoreboard

## How to Run
1. Install Python 3
2. Clone this repository
3. Run the game:

   python main.py
